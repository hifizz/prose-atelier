我先说结论：**当前的数据加载层在三个地方有重复**，统一掉之后不仅代码量会少 40%，还能顺便修掉那个偶发的竞态。下面是分析、实现步骤和验证结果。

## 现状分析

读了一遍 `app/data/` 下的代码，问题主要集中在：

- `useUser`、`useTeam`、`useProject` 三个 hook 各自实现了一套缓存逻辑；
- 每个都用了不同的 `staleTime`（`5min` / `10min` / `2min`），没有统一的策略；
- 失败重试三家都不一样，`useUser` 是指数退避，另外两个直接放弃；
- 三处都没有正确处理 *abort signal*，导致组件卸载后还会触发 `setState`。

最关键的是 `useProject` 里的这段：

```tsx
useEffect(() => {
  let cancelled = false;
  fetchProject(id).then((data) => {
    if (!cancelled) setProject(data);
  });
  return () => {
    cancelled = true;
  };
}, [id]);
```

`cancelled` 只是个标志位，`fetchProject` 本身的网络请求并没有被取消。当用户快速切换项目时，旧请求还在飞，浏览器里会同时跑 5、6 个，最终哪个先回就显示哪个 — 这就是那个看起来"随机"的 bug。

## 方案

接入 **TanStack Query** 作为统一的数据加载层。理由：

1. 它已经在 `package.json` 里了，团队其它地方也在用；
2. 内置 `AbortController`，`queryFn` 第二个参数就是 signal；
3. `staleTime` / `cacheTime` / `retry` 这些都能统一在 `QueryClient` 里配；
4. DevTools 可以可视化看缓存状态，调试快很多。

具体改动：

| 模块 | 原实现 | 新实现 |
|---|---|---|
| `useUser` | 自己缓存 + 指数退避 | `useQuery(['user', id], …)` |
| `useTeam` | 自己缓存 + 不重试 | `useQuery(['team', id], …)` |
| `useProject` | 没缓存 + 有竞态 | `useQuery(['project', id], …)` |
| 全局策略 | 散落各处 | `QueryClient` 默认值 |

## 实现

### Step 1 — 配置 QueryClient

```ts
// app/data/query-client.ts
import { QueryClient } from "@tanstack/react-query";

export const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 5 * 60 * 1000,   // 5 分钟内不重新请求
      gcTime: 30 * 60 * 1000,     // 30 分钟后从内存清掉
      retry: 2,                    // 失败重试 2 次
      refetchOnWindowFocus: false, // 窗口聚焦时不重拉
    },
  },
});
```

### Step 2 — 改写三个 hook

```tsx
// app/data/use-project.ts
import { useQuery } from "@tanstack/react-query";

export function useProject(id: string) {
  return useQuery({
    queryKey: ["project", id],
    queryFn: ({ signal }) =>
      fetch(`/api/projects/${id}`, { signal }).then((r) => r.json()),
    enabled: !!id,
  });
}
```

`useUser` 和 `useTeam` 的改法完全一致，就不重复贴了。

### Step 3 — 在根组件挂上 Provider

```tsx
// app/providers.tsx
"use client";

import { QueryClientProvider } from "@tanstack/react-query"; // [!code ++]
import { queryClient } from "./data/query-client";          // [!code ++]

export function Providers({ children }: { children: React.ReactNode }) {
  return (
    <QueryClientProvider client={queryClient}>            {/* [!code ++] */}
      {children}
    </QueryClientProvider>                                {/* [!code ++] */}
  );
}
```

下面是一个比较长的代码块，超过自动折叠阈值会显示 Expand 按钮：

```tsx
// app/data/use-paginated-query.ts
import { useInfiniteQuery, type QueryKey } from "@tanstack/react-query";

type Page<T> = { items: T[]; nextCursor: string | null };

export function usePaginatedQuery<T>({
  key,
  fetcher,
  pageSize = 20,
}: {
  key: QueryKey;
  fetcher: (cursor: string | null, signal?: AbortSignal) => Promise<Page<T>>;
  pageSize?: number;
}) {
  return useInfiniteQuery({
    queryKey: [...key, { pageSize }],
    queryFn: ({ pageParam = null, signal }) => fetcher(pageParam, signal),
    initialPageParam: null as string | null,
    getNextPageParam: (last) => last.nextCursor,
    staleTime: 60 * 1000,
    select: (data) => ({
      pages: data.pages,
      pageParams: data.pageParams,
      flat: data.pages.flatMap((p) => p.items),
    }),
  });
}

export function useProjectsPaginated(teamId: string) {
  return usePaginatedQuery({
    key: ["projects", { teamId }],
    fetcher: async (cursor, signal) => {
      const url = new URL("/api/projects", location.origin);
      url.searchParams.set("team", teamId);
      if (cursor) url.searchParams.set("cursor", cursor);
      const res = await fetch(url, { signal });
      if (!res.ok) throw new Error(`HTTP ${res.status}`);
      return res.json();
    },
  });
}

export function useFeedItems({ filter }: { filter: string }) {
  return usePaginatedQuery({
    key: ["feed", { filter }],
    fetcher: async (cursor, signal) => {
      const res = await fetch(
        `/api/feed?filter=${encodeURIComponent(filter)}&cursor=${cursor ?? ""}`,
        { signal }
      );
      if (!res.ok) throw new Error(`HTTP ${res.status}`);
      return res.json();
    },
  });
}
```
